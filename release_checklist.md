# Release Checklist

## Before release
- [ ] Intent and spec still agree
- [ ] Source owner is visible
- [ ] Conflicting guidance triggers a safe handoff
- [ ] Accessibility has been reviewed
- [ ] No secret or private student data is present
- [ ] Verification evidence is attached
- [ ] A human reviewer approves release

## Decision
- [ ] Ready to release
- [ ] Blocked - return to the appropriate earlier stage
